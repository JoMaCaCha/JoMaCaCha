# Johan Manuel Cabrera Chavarro

**Senior Software Engineer · AI Systems Engineer** · Neiva, Colombia

I build production backends and AI-powered products end to end: data capture pipelines, LLM integrations, cloud deployment and the tests that keep them reliable. I have 6+ years of experience shipping software in healthtech (medical imaging, PACS) and in social data intelligence.

## What I work on

- **LLM-powered applications:** multi-step AI pipelines and conversational agents on OpenAI, Gemini and Claude, with streaming responses (SSE).
- **Data capture at scale:** distributed extraction services with FastAPI, Celery, Redis and PostgreSQL, built with caching, rate limiting, retries with backoff and observability.
- **Cloud-native backends on Google Cloud:** Cloud Run, Cloud Tasks, Pub/Sub, Firestore and GKE, with CI/CD on GitHub Actions and Docker.
- **Medical imaging and computer vision:** a PACS in C#/ASP.NET and SQL Server, deep learning models for diagnostic support, and real-time vital-sign estimation from video (remote photoplethysmography).
